# DASH-Gabinete-Social
Tablero interactivo de monitoreo social del Gobierno de Río Cuarto (Gabinete Social + La Muni en tu Barrio). Visualiza y georreferencia datos de encuestas sobre vivienda, salud, niñez, adultos mayores, discapacidad, conectividad, programas y servicios por barrio, facilitando el diagnóstico territorial y la toma de decisiones.
